# MIAN X NIAZI — TikTok & Instagram Downloader

A simple, mobile-friendly TikTok and Instagram video downloader website with an RGB-style design.

## Features

- TikTok downloader
- Instagram Reel downloader
- Paste and Clear buttons
- Small RGB download button
- Video preview
- HD and MP3 options for TikTok when available
- RGB animated buttons
- Falling `MIAN X NIAZI` coding background
- Mobile-friendly design
- Custom website image
- TikTok and WhatsApp buttons

## Live Website

https://my-insta-api-seven.vercel.app

## Deployment

1. Upload the project files to GitHub.
2. Import the GitHub repository into Vercel.
3. Deploy the project.
4. Push future changes to GitHub and Vercel will redeploy automatically.

## Notes

- Use valid TikTok video or Instagram Reel URLs in the downloader.
- A TikTok profile URL is not a TikTok video URL.
- Third-party downloader APIs may change or stop working.
- Direct media downloads can sometimes be affected by browser CORS or remote-server settings.
- Only download content you have permission to download.
